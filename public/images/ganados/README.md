# Capturas de pronósticos ganados

Deja aquí las capturas de los picks ganados y aparecerán automáticamente en el
carrusel de la página **/telegram**, sin tocar código.

- Las capturas se muestran en una fila: se ven todas las que caben a lo ancho y
  el resto se desliza con las flechas, arrastrando con el ratón o deslizando el
  dedo en el móvil (el carrusel no se mueve si todas caben).
- Formatos admitidos: `.png`, `.jpg` / `.jpeg`, `.webp`, `.avif` y `.gif`.
- El orden del carrusel es el orden alfabético del nombre del fichero, así que
  numera las fotos para controlarlo: `01-ganado-madrid.png`, `02-ganado-nba.jpg`...
- Los ficheros que empiezan por punto (`.gitkeep`) y los que no son imágenes se
  ignoran.
- Si la carpeta está vacía, el carrusel muestra un aviso de "Todavía no hay
  capturas" en lugar de un hueco roto.
